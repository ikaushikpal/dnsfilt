How DNS Resolution Works

The Domain Name System (DNS) acts as the phonebook of the Internet. When you type a hostname like google.com into your browser or terminal, your system needs to translate that human-readable name into a machine-readable IP address (142.250.146.101).

DNSFilt Query Resolution Pipeline:

1. Client Request UDP Packet on Port 2053
2. L1 Caffeine Cache JVM Memory (< 0.1ms Hit)
3. Security Blocklist Aiven Valkey Redis Set
4. Upstream Resolver Google / Cloudflare DNS

DNS Record Types Reference Guide

Type Full Name Primary Purpose & Example
A Address Record Maps a hostname to a 32-bit IPv4 address (e.g. 142.250.146.101).
AAAA IPv6 Address Record Maps a hostname to a 128-bit IPv6 address (e.g. 2607:f8b0::200e).
CNAME Canonical Name Record Aliases one domain name to another canonical domain.
MX Mail Exchange Record Directs email traffic to the specified mail server hosts.
TXT Text Record Stores arbitrary text, heavily used for SPF email security & domain verification.
NS Name Server Record Delegates a DNS zone to use specific authoritative name servers.
SOA Start of Authority Record Contains core administrative data about a DNS zone (serial, contact email, refresh timers).
PTR Pointer Record Used for Reverse DNS (rDNS) lookups to resolve an IP address to a domain.
SRV Service Location Record Defines hostname and port numbers for specific services like SIP and LDAP.
