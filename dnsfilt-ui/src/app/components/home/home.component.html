About DNSFilt

About DNSFilt Architecture

DNSFilt is an open-source, high-performance security DNS resolver built on Java 21 Virtual Threads, Caffeine L1 cache, Aiven Valkey Redis L2 storage, and real-time streaming Kafka query audit logging. Mitigates malware, phishing, and bad actors at the DNS layer before network sockets ever open.

Architecture Performance

Core Engine Features

Java 21 Virtual Threads

Concurrent processing of 50,000+ DNS queries per second using lightweight Virtual Threads with minimal memory footprint.

Zero-Latency L1 Cache

Caffeine in-memory JVM cache delivers sub-millisecond (< 0.1 ms) resolution for repeat hostname lookups.

Aiven Valkey L2 Storage

TLS-encrypted cloud L2 cache backing store for distributed persistence across global datacenter clusters.

Real-Time Threat Block

Blocks malware, phishing, and ad-tracking domains instantly before network connections are ever established.

Kafka Audit Telemetry

Asynchronous streaming of query audit logs to Aiven Kafka for live telemetry analytics without blocking responses.

Multi-OS Command Suite

Native terminal commands for macOS, Linux, Windows PowerShell, and Windows CMD for A, AAAA, CNAME, MX, TXT lookups.
