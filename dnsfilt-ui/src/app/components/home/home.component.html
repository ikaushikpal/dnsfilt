About DNSFilt

A Security Layer at the DNS Level

DNSFilt is an open-source, high-performance security DNS resolver designed to protect users and networks at one of the earliest points of network communication: the DNS request.

The goal is simple: fast DNS resolution with security built directly into the resolution path.
