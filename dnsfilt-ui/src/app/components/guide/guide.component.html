Device Configuration

How to Connect to DNSFilt

Configure your operating system, mobile device, or home router to route all DNS queries through DNSFilt for high-speed resolution and threat filtering.

Primary DNS Server ACTIVE

130.210.34.226

Points directly to your dedicated public dnsfilt-resolver security cluster.

Secondary DNS (Fallback) BACKUP

1.1.1.1

Standard public DNS fallback if the primary server is unreachable.

@if (selectedOs() === 'macos') {

macOS (Ventura, Sonoma, Sequoia & later)

  1. Open Apple Menu → System Settings.
  2. Select Network from the left sidebar.
  3. Click on your active connection (Wi-Fi or Ethernet), then click Details....
  4. Navigate to the DNS tab in the sidebar.
  5. Under DNS Servers, click the + (Add) button.
  6. Enter 130.210.34.226 as primary DNS.
  7. Optionally add 1.1.1.1 as backup.
  8. Click OK, then Apply.
} @if (selectedOs() === 'windows') {

Windows 11 / Windows 10

  1. Open Settings (Win + I).
  2. Go to Network & Internet → Select Wi-Fi or Ethernet.
  3. Click on Hardware properties.
  4. Next to DNS server assignment, click Edit.
  5. Change from Automatic (DHCP) to Manual and toggle IPv4 to On.
  6. In Preferred DNS, type: 130.210.34.226
  7. In Alternate DNS, type: 1.1.1.1
  8. Click Save.
} @if (selectedOs() === 'linux') {

Linux (systemd-resolved / resolv.conf)

Edit your systemd-resolved configuration:

# Edit /etc/systemd/resolved.conf
sudo nano /etc/systemd/resolved.conf
# Set DNS line:
DNS=130.210.34.226 1.1.1.1
# Restart systemd-resolved:
sudo systemctl restart systemd-resolved
} @if (selectedOs() === 'ios') {

iPhone & iPad (iOS / iPadOS)

  1. Open Settings → Wi-Fi.
  2. Tap the ⓘ (info) icon next to your connected Wi-Fi network.
  3. Scroll down and tap Configure DNS.
  4. Select Manual.
  5. Tap + Add Server.
  6. Enter 130.210.34.226
  7. Tap Save in the top-right corner.
} @if (selectedOs() === 'android') {

Android (Wi-Fi Settings)

  1. Open Settings → Network & internet → Internet.
  2. Tap the Settings (gear) icon next to your connected Wi-Fi network.
  3. Tap the Edit / Pencil icon (or Advanced Options).
  4. Change IP settings from DHCP to Static.
  5. In DNS 1, enter 130.210.34.226
  6. In DNS 2, enter 1.1.1.1
  7. Tap Save.
} @if (selectedOs() === 'router') {

Home Router (Protect All Household Devices)

  1. Open a browser and log in to your router gateway (typically 192.168.1.1 or 192.168.0.1).
  2. Find the WAN / Internet or DHCP Server settings page.
  3. Locate the DNS Server field.
  4. Set Primary DNS to 130.210.34.226
  5. Set Secondary DNS to 1.1.1.1
  6. Click Save / Apply. All devices on your network will automatically resolve through DNSFilt!
}
